# 🎬 VideoStream — Скрипт видеоплатформы с парсером

Полноценный скрипт видеосервиса с автоматическим парсером видео по ссылкам.
Аналог YouTube/RuTube с собственной базой данных.

---

## 📁 Состав проекта

```
index.html          — Фронтенд (видеоплатформа, интерфейс)
parser_backend.py   — Бэкенд (API + парсер + БД)
requirements.txt    — Зависимости Python
README.md           — Эта инструкция
```

---

## ⚙️ Установка и запуск

### 1. Установи Python (если нет)
https://python.org/downloads — версия 3.10+

### 2. Установи зависимости
```bash
pip install -r requirements.txt
```

### 3. Запусти бэкенд
```bash
python parser_backend.py
```
Сервер запустится на: **http://localhost:5000**

### 4. Открой фронтенд
Просто открой файл `index.html` в браузере — двойной клик.

## 🚀 Как пользоваться

### Парсинг одного видео
1. Нажми вкладку **"⚙️ Парсер"** или смотри правую панель
2. Вставь ссылку на страницу с видео
3. Нажми **"Спарсить видео"**
4. Скрипт автоматически найдёт: заголовок, описание, превью, прямую ссылку

### Массовый парсинг
1. Вставь ссылку на каталог / страницу со списком видео
2. Выбери количество видео (до 50)
3. Нажми **"Массовый парсинг"**
4. Все найденные видео добавятся в базу

### Поиск
- Поисковая строка в шапке — поиск по названию, автору, описанию
- Результаты обновляются в реальном времени

### Просмотр видео
- Нажми на любую карточку — откроется плеер
- Поддержка: MP4, WebM, HLS (m3u8), iFrame embed

## 🔧 Что парсер умеет вытаскивать

| Данные       | Откуда берёт                                      |
|--------------|---------------------------------------------------|
| Заголовок    | og:title, twitter:title, h1, title тега           |
| Описание     | og:description, meta description                  |
| Превью       | og:image, twitter:image                           |
| Видео URL    | og:video, тег video/source, паттерны в JS коде    |
| Автор        | meta author, og:site_name                         |

## 🌐 API эндпоинты

| Метод | URL                    | Описание                        |
|-------|------------------------|---------------------------------|
| POST  | /api/parse             | Парсинг одной ссылки            |
| POST  | /api/parse-bulk        | Массовый парсинг каталога       |
| GET   | /api/videos            | Список видео (с поиском, пагинацией) |
| GET   | /api/videos/:id        | Одно видео по ID                |
| DELETE| /api/videos/:id        | Удалить видео                   |

### Пример запроса:
```json
POST /api/parse
{ "url": "https://example.com/video/123" }
```

### Ответ:
```json
{
  "title": "Название видео",
  "description": "Описание...",
  "thumbnail": "https://.../thumb.jpg",
  "video_url": "https://.../video.mp4",
  "source_url": "https://example.com/video/123",
  "author": "Канал",
  "saved": true
}
```

## 💾 База данных

SQLite файл `videos.db` создаётся автоматически рядом с `parser_backend.py`.
Хранит все спарсенные видео. Можно открыть через DB Browser for SQLite.

---

## ⚠️ Важные нюансы

- **Некоторые сайты защищены** от парсинга (Cloudflare, авторизация).
  В таком случае видео не спарсится — это нормально.
- **HLS (m3u8)** работает в Safari нативно. В Chrome нужен плагин hls.js
  (можно добавить по желанию).
- Парсер **не обходит DRM** (защищённый контент).
- Для продакшена рекомендуется добавить **прокси/ротацию User-Agent**.
